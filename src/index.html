Bank Monitor (v0)

Tutorial

How to use

• Cette application sert à gérer la manière dont l'argent est répartit dans chaques catégories (à l'aide d'une banque virtuel) pour faire les comptes.

Bank Stats

• Permet de voir la quantité et le pourcentage d'argent actuellement réservé pour chaque catégories.

Earning

• Permet de créer des configurations permettant de répartir une certaine somme dans chaque catégories (exemple: 10€ divertissement, 30% nourriture, 70% logement) ou bien de transférer entre deux catégories.

Spending

• Permet de retirer de l'argent dans la banque virtuel dans une catégorie.

Activity Stats

• Permet de voir l'historique de la banque (ajout ou retrait d'argent) ainsi que de faire différente statistiques sur une période choisis.
